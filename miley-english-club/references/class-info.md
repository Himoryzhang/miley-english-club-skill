## 课程介绍

来源：麦粒英语可乐部官网  
链接：https://mp.weixin.qq.com/s/u_RWjbyFULLx6U79YR0OtQ  
更新时间：2022-11-27

1. 精品口语班课Speaking

话题制精品口语课程，每次课一个话题，让您通过多样的内容，进入身临其境的口语情景。专业的英语测评精准您的口语级别，再根据您的实际英语水平分级授课，级别为初级、初中级、中级、中高级和高级，内容涵盖日常生活、社会热点、商务、政治、旅行等。老师通过各种有趣的形式引入话题，再展开单词、表达方式、俚语、谚语、成语、对话或谈论。上课氛围轻松惬意，老师亲切友好、在无压力的状态下引导大家开口讲英语、提升词汇量、掌握更多热点词汇。

2. Skill Class

知识储备课程包括词汇、语法、写作、阅读、语音等知识内容。分级别上课、完善知识结构。

3. Culture Class

文化类课程内容涵盖国外风俗习惯、西方人的生活轶事、西方节日、英国皇室家族、娱乐、世界各地风光等内容。用英语打开世界的窗口、敲开世界的大门~

4. Club Class

俱乐部课通过形式多样的活动让大家学习英语，如美剧、外教教唱英文歌、游戏、手工课等。

5. VIP定制课程

VIP课程根据您的需求为您量身定做。无论您需要基础提升、面试技巧、商务函电，还是雅思、托福，我们都能为您提供个性化的解决方案。时间自由支配、内容和进度随时调整，让您的学习更有针对性、更有成效。
